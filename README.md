# NoorBot (نور بوت)

**نور بوت** هو مساعد آلي ذكي (Conversational Agent) مبني باستخدام تقنيات التعلم العميق (Deep Learning) ومعالجة اللغات الطبيعية (NLP) لفهم استفسارات المستخدمين المتعلقة بالأحاديث النبوية والأذكار، وتصنيفها، والرد عليها بدقة.

## المميزات (Features)
* **تصنيف النوايا (Intent Classification):** يستخدم نموذج شبكات عصبية ثنائية الاتجاه (BiLSTM) لتصنيف نصوص المستخدم إلى فئات متعددة بدقة عالية.
* **استرجاع المعلومات (Retrieval-based Mechanism):** يعتمد على خوارزميات `TF-IDF` و `Cosine Similarity` للبحث عن أدق إجابة في قاعدة البيانات، خاصة عند البحث عن الأحاديث.
* **معالجة النصوص العربية:** يتضمن نظاماً مدمجاً لتنظيف النصوص العربية (إزالة التشكيل، توحيد الحروف، وإزالة الرموز) لضمان أعلى مستوى من دقة الفهم.
* **التفاعل الطبيعي:** يدعم عبارات الترحيب، والتعريف، والوداع لتجربة مستخدم سلسة وودية.

## التقنيات المستخدمة (Tech Stack)
* **اللغة:** Python
* **التعلم العميق:** TensorFlow & Keras (BiLSTM, Embedding, Dropout)
* **تعلم الآلة ومعالجة اللغات:** Scikit-Learn (TF-IDF Vectorizer, Cosine Similarity, LabelEncoder)
* **تحليل البيانات:** Pandas & NumPy
* **الرسم البياني وتقييم النموذج:** Matplotlib & Seaborn

## قواعد البيانات (Datasets)
تم تدريب وبناء قاعدة المعرفة الخاصة بالبوت من خلال دمج وهندسة عدة مصادر موثوقة:
* **الأذكار:** تم جلب بيانات الأذكار المجمعة (Adhkar JSON) وتوسيعها.
* **الأحاديث النبوية:** تم استخدام قواعد بيانات الأحاديث من Kaggle (تتضمن: صحيح البخاري، صحيح مسلم، سنن الترمذي، ومسند أحمد).

## تقييم أداء النموذج (Model Evaluation)
أظهر نموذج `BiLSTM` أداءً ممتازاً في تصنيف نوايا المستخدمين (Intent Classification) والتعميم على البيانات غير المرئية دون الوقوع في مشكلة الـ Overfitting. كما يتم الاستعانة بتحليل التشابه (Cosine Similarity) كطبقة إضافية لضمان دقة الردود في استفسارات الأحاديث.

## طريقة الاستخدام (How to Use)
1. قم بتحميل ملف `NoorBot.ipynb`.
2. افتح الملف باستخدام [Google Colab](https://colab.research.google.com/) أو Jupyter Notebook.
3. قم بتشغيل الخلايا بالترتيب، بدءاً من استيراد المكتبات وتحميل البيانات، مروراً بتدريب النموذج، وصولاً إلى الخلية الأخيرة الخاصة بـ `Interactive Chat Loop`.
4. اكتب استفسارك باللغة العربية في مربع الإدخال وتحدث مع البوت!
